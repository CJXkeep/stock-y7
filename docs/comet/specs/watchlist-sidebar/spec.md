# Capability: 自选股侧边栏与分组（watchlist-sidebar）

## 概述

归档后，自选股从顶栏下拉浮层迁移为常驻左侧边栏，支持同花顺式分组管理、行情列与信号角标，并提供导出/导入 JSON 兜底。

## 完整行为

### 1. 布局

- 侧边栏固定于主区左侧，展开宽度 260px；收起为 48px 图标栏（显示分组首字/数量角标）；
- 顶栏「自选」按钮改为侧边栏开合开关；「历史/多股一览/信号档案/核心池」下拉面板保持现状不变；
- 开合状态存 localStorage（`qs_sidebar_open`），刷新后恢复；
- 主区（图表 + 右侧信号列）自适应剩余宽度；开合时对全部 ECharts 实例调用 resize。

### 2. 数据模型与迁移

```text
localStorage 键：
  qs_watch_groups  新增。[{id, name, order, collapsed, codes: [code,...]}]
                   首个分组固定 id="default"，name="我的自选"，不可删除。
  qs_watch_stocks  新增。{code: {name, action, score, price, pct, addedAt, pinned}}
  qs_watchlist     旧键，只读不删。首次加载时若存在且 qs_watch_groups 未初始化，
                   将其条目按原顺序迁入"我的自选"。
```

- 迁移在页面加载时自动执行一次；迁移前后条目数一致才写入新键；
- 星标加入：分析页 ★ 加入当前选中分组（默认"我的自选"）；已存在时星标为移除。

### 3. 分组操作

- 新建分组：侧边栏底部"+ 新建分组"；名称内联输入，回车确认，空名取消；
- 重命名：组头双击或右键菜单；
- 删除：右键菜单；确认弹窗提示"成员将移入我的自选"；删除后成员回落默认组；
- 折叠/展开：组头点击箭头；状态存 `collapsed`；
- 分组排序：拖拽组头调整上下顺序（存 `order`）。

### 4. 股票行交互

- 行内容：名称 / 代码 / 现价 / 涨跌幅（涨红跌绿着色）/ 信号角标（买=红、卖=绿、观=灰）；
- 单击行：切换分析标的（调用现有 analyze），侧边栏保持打开，不高亮丢失；
- 右键菜单：移动到分组（子菜单列出全部分组）/ 置顶（组内置顶，`pinned=true`）/ 删除；
- 拖拽：股票行可跨分组拖动，也可组内上下排序；HTML5 drag & drop 实现；
- 组头统计：成员数 + 组内涨跌家数（如 "5只 · 3涨2跌"）。

### 5. 行情刷新

- 盘中判定：周一至周五本地时间 9:15–15:05（前端启发式，节假日靠数据自然过期兜底）；
- 盘中每 5 秒一轮并行拉取所有可见分组股票的 `/api/quote`（复用现有多股一览并发模式）；非盘中降频至 60 秒；
- 页签隐藏（document.hidden）时暂停轮询，恢复可见时立即刷一轮；
- P3 增强：后端新增 `GET /api/quotes?codes=a,b,c` 批量端点（走既有 host 池与缓存），前端切换到单请求批量模式，降低被 WAF 拦截概率；行为与逐只拉取一致。

### 6. 导出/导入

- 设置弹层提供「导出自选」：下载 `watchlist-backup-YYYYMMDD.json`，内容为 `{version:1, exportedAt, groups, stocks}`；
- 「导入自选」：选择文件 → 校验 version 与结构 → 合并策略"同名分组保留现名，股票按 code 去重保留较新 addedAt"→ 导入成功 toast 显示导入条数；
- 结构非法时拒绝并提示原因，不改动现有数据。

## 边界与回退

- localStorage 不可用（隐私模式）：功能降级为内存态并顶部提示"自选股不会被保存"；
- 分组数为 1 且为空时显示引导文案（沿用现有空态样式）；
- 迁移失败（JSON 解析异常）时不写新键，保持旧键原样并在控制台告警。
