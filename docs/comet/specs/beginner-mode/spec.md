# Capability: 小白模式增强（beginner-mode）

## 概述

小白模式从"隐藏专业信息"升级为"翻译专业信息"。归档后，模式切换（顶栏 小白/专业）在保留现有简化行为的基础上，提供风险置顶解读、三段式结论、术语即点即译与信号逐条解释。

## 完整行为

### 1. 模式切换（沿用现有入口）

- 顶栏 专业/小白 切换按钮行为不变；`body.mode-pro` / `body.mode-simple` 类切换机制不变；
- 小白模式继续隐藏 CANSLIM 七格、显示简化版动量卡与缠论白话总结；
- **变更**：`risk` 卡从小白折叠清单中移除；小白模式下任何卡片折叠都不影响风险横幅的可见性。

### 2. 风险置顶横幅

- 触发：`signal.risk_warnings` 非空时，「AI 分析结论」卡在正文之前渲染风险横幅（仅小白模式）；
- 样式：红/橙渐变底色横幅，含 ⚠ 图标与风险条数；
- 每条风险渲染两行：大白话解释 + "建议：xxx"动作行；
- 数据来源：优先按 `signal.risk_codes`（结构化码）查 `RISK_EXPLAIN` 字典；无 code 时按 `risk_warnings` 文本关键词匹配；两者都未命中回退显示原文并附通用提示；
- 字典初始覆盖：price_below_ma20 / price_down_volume_up / obv_down / ma20_down / price_below_ma60 / 市场环境偏空(m_score<30) / 盈亏比倒挂 / 盈亏比偏低；
- 横幅底部固定小字："以上为规则解读，仅供参考，非投资建议。"

### 3. 三段式结论

小白模式下结论区渲染三段卡片（数据全部来自现有 signal 返回字段，前端拼装）：

| 段 | 图标 | 内容来源 |
|---|---|---|
| 现状 | 📌 | trend.direction/strength、volume_price.pattern、momentum.m_score |
| 风险与机会 | ⚠️ | risk_level、buy_signals/sell_signals 条数与要点、大盘环境 |
| 现在该做什么 | ✅ | 最终 action、position_advice、trade_plan 关键价（入场/止损/目标）、观望时给出可操作的关注条件（如"收盘价站回 MA20 再关注"，MA20 取 key_levels 或 klines 计算） |

- 专业模式保持原 plain_summary 单句渲染，不出现三段式。

### 4. 术语即点即译

- `glossary.js` 导出术语词典（≥10 条）：MA5/MA10/MA20/MA60、OBV、ATR、盈亏比、换手率、量比、缠论一类/二类买卖点、中枢、M分、CANSLIM、前复权；
- 渲染范围：三段式结论、风险横幅解释文本、买卖信号列表；
- 术语渲染为虚线下划线 chip；点击弹出气泡卡（术语全称 + 大白话解释 + 一句示例），点击气泡外区域或再次点击关闭；同一时刻最多一个气泡；
- 移动端不在本期范围，但气泡需可由 click 触发（不依赖 hover）。

### 5. 信号逐条"为什么"

- 买卖信号列表每条右侧新增"为什么？"链接（仅小白模式）；
- 点击展开一行解释：该信号的触发规则原文 + 大白话含义；
- 展开状态不持久化；切换股票后收起。

## 边界与回退

- `risk_codes` 与 `risk_warnings` 同时为空时不渲染横幅（正常无风险情形，不显示"没有风险"占位）；
- 字典未收录术语保持普通文本样式，不报错；
- 专业↔小白切换即时生效，无需刷新。
