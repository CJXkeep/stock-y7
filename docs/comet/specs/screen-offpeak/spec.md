# Spec: screen-offpeak（选股错峰与限流治理）

归档后 capability 的完整行为规格。

## 1. 同步窗口错峰

- K 线同步窗口 = `KLINE_SYNC_AT`（当前 15:30）起的 `SYNC_WINDOW_MIN`（实现常量，默认 15 分钟）；
- 选股调度触发时若处于同步窗口内：本轮**跳过选股**（持仓巡检与净值快照照常执行），state 记录推迟原因（含下次可选时间）；
- `run_once force=true` 不受窗口限制（手动触发视为知情操作）。

## 2. WAF 提前终止

- 选股初筛阶段连续 `SCREEN_ABORT_THRESHOLD`（实现常量，默认 20）只候选因行情源拦截（WAF/限流类错误）而失败时，提前终止本轮选股；
- 终止时 state 标记 `source_throttled=true`（含终止时已评估数量），本轮不产生买入；
- 标记为单轮状态：下一轮选股开始时清除；
- 已产生的部分初筛结果不用于买入（避免样本截断偏差）。
