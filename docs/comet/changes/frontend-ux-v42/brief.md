# Outcome

看板前端完成三块体验升级，形成 v4.2：

1. **小白模式增强**：风险提示在小白模式下置顶必现且带大白话解读；结论从一句话模板扩展为"现状/风险与机会/现在该做什么"三段式；术语即点即译。让不懂技术指标的用户能看懂结论并知道当前该做什么。
2. **同花顺式自选股侧边栏**：常驻左侧、可收起的侧边栏取代现有下拉浮层中的自选股页签；支持自定义分组（新建/重命名/删除/拖拽归组/组内排序）、行情涨跌列、信号角标、导出/导入 JSON。
3. **三档动效系统**：关/标准/炫酷/自动 四选一的全局动效开关（默认自动），标准档提供微交互与内容入场动效，炫酷档叠加图表首帧动画与信号扩散效果，全部动效带性能护栏。

# Scope

- `dashboard/` 前端（P0 先拆分为 style.css / app.js / glossary.js，index.html 只留结构；后端静态服务已支持，零后端改动）
- 小白模式渲染逻辑与术语词典（前端常量，复用后端 `risk_codes` 结构化码）
- 自选股数据模型：新增 `qs_watch_groups`（分组）+ `qs_watch_stocks`（股票详情），旧 `qs_watchlist` 自动迁移且旧键保留
- 侧边栏行情刷新：P1 复用现有并行 fetch（盘中 5s / 盘后 60s）；P3 增加后端批量接口 `GET /api/quotes?codes=`（本 change 内唯一后端增量）
- 设置弹层：动效档位切换 + 自选导出/导入入口

# Non-goals

- 不做跨设备账号同步（仅导出/导入 JSON，用户已确认）
- 历史/多股一览/信号档案/核心池页签**不**搬入侧边栏（维持现有下拉面板，下一期评估）
- 不改动分析引擎与信号评分逻辑（signal_engine.py / app.py 评分与后处理不动）
- 不做移动端/响应式重设计
- 不引入前端框架、npm 构建链或打包工具（保持原生 JS + ECharts CDN）
- 氛围光等纯装饰效果只出现在炫酷档，不进默认档

# Acceptance examples

- A1: 小白模式下，`risk_warnings` 非空时「AI 分析结论」卡顶部渲染风险横幅；风险卡不在小白折叠清单中，横幅不因任何卡片折叠而消失
- A2: 小白模式下每条风险显示"大白话解释 + 建议动作"（按 `risk_codes` 映射 RISK_EXPLAIN 字典）；未收录的 code 回退显示原文，不报错
- A3: 小白模式结论区按 现状/风险与机会/现在该做什么 三段渲染（数据全部来自现有 signal 字段）；专业模式保持原一句话总结，视觉不变
- A4: 结论正文与信号列表中的词典术语（≥10 条：MA20/OBV/ATR/盈亏比/换手率/缠论买卖点/中枢/M分 等）渲染为可点击样式，点击弹出解释气泡，点空白或再点击关闭
- A5: 左侧常驻侧边栏可在 260px 展开与 48px 图标栏间收放，刷新后状态保持；开合时主图表区 ECharts 自适应 resize 无错位
- A6: 旧版平铺自选数据首次加载自动迁入"我的自选"分组且条目零丢失，旧 localStorage 键保留不删；分组支持新建/重命名/删除，删除分组成员自动回落"我的自选"
- A7: 支持拖拽股票跨分组移动与组内排序；行右键菜单提供 移动到分组/置顶/删除 三项且全部生效
- A8: 盘中（周一至五 9:15–15:05）侧边栏行情每 5 秒刷新现价与涨跌幅并红绿着色；非盘中降频至 60 秒；点击股票行切换分析标的且侧边栏保持打开
- A9: 设置面板提供自选导出/导入 JSON；导出文件含分组结构与股票详情，导入后分组完整恢复
- A10: 设置弹层提供动效档位 关/标准/炫酷/自动，切换即时生效并 localStorage 记忆；自动档在 deviceMemory<4 或 prefers-reduced-motion 时等效"关"
- A11: 标准档包含卡片进入 stagger 淡入、分析分数数字滚动、骨架屏 loading；切到"关"后三者全部消失且功能不受影响
- A12: 炫酷档下 ECharts 首次渲染有入场动画，而行情轮询刷新仍为 animation:false；信号变更时自选角标出现扩散动画
- A13: 全部动画仅使用 transform/opacity；系统开启 prefers-reduced-motion: reduce 时任何档位均无动画
- A14: P0 拆分后通过 `python app.py` 访问看板，现有功能全部回归可用（分析/K线/自选/历史/多股一览/信号档案/核心池/小白专业切换/分时），控制台无 404 与 JS 报错

# Constraints and invariants

- 发行结构保持"单文件夹静态文件"（dashboard/ 目录），index.html 已带 no-cache 头，无浏览器缓存升级问题
- ECharts 数据轮询刷新永远 `animation:false`（保住既有性能决策）；动画只允许出现在首帧渲染
- 所有动画仅用 transform/opacity（合成层），禁止 width/top/left 动画；数字滚动用 requestAnimationFrame 且页签隐藏时暂停
- localStorage 旧键（qs_watchlist 等）保留不删，迁移可回滚；迁移前先做导出快照兜底
- FX=关 时 JS 侧直接跳过动画调度逻辑，不依赖 CSS 硬扛
- 所有面向小白的解读文案附"仅供参考，非投资建议"口径（沿用项目既有声明）
- 后端仅允许 P3 新增 `/api/quotes` 批量行情端点，走既有 host 池与节流，不改动现有端点行为

# Decisions

- D1 跨设备同步：不做账号体系，本期仅导出/导入 JSON（用户 2026-08-23 明确确认）
- D2 历史/多股一览/信号档案/核心池页签不搬入侧边栏（按推荐默认，随最终确认生效）
- D3 氛围光等纯装饰效果仅炫酷档提供，默认自动档不含（按推荐默认，随最终确认生效）
- D4 侧边栏位于左侧、可收起为图标栏（用户指定"借鉴同花顺"）
- D5 动效默认档位为"自动"（deviceMemory<4 或 CPU≤4 核或 prefers-reduced-motion → 关，否则标准）
- D6 P0 先拆分 CSS/JS 再开发新特性；工作区隔离采用当前目录 main 直推（用户确认），今日 bug 修复已单独提交（4e9ef3f）
