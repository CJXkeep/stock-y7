# Outcome

消除「止损/卖出信号在突破模块拿 60 分、高于中性（无信号 50 分）」的反向加分缺陷：刚触发止损的股票，其突破子分不再高于从未突破的股票，也不再与「持仓」同分；把引擎分档阈值与后处理分级阈值收敛到 params_override 同一事实源，消除「override 改引擎阈值、后处理分级仍用旧常量」的静默不一致；并引用/复核既有 I12.1 卖出规则网格（含 3% 高点回撤档）作为敏感性对照证据。最终止损子分取值（40 或 50）由清缓存后的全量重放对照数据定夺。

# Scope

- `analysis/signal_engine.py`：
  - `_breakout_to_score`：把「多头止损/卖出」从与「持仓」相同的 60 分中剥离，降至 40/50 双候选中的最终选定值（双候选需可切换，供全量重放对照）；「持仓」维持 60、「空头平仓」偏多加分维持现状。仅止损/卖出分支改变。
  - 附带：replay 缓存失效只认 `signal_postprocess.py` 的 `policy_hash`，而本计分改动落在 `signal_engine.py`——对照实验前必须清除/失效既有 `cache.json`，否则旧缓存被误用、对照失真。
- `analysis/signal_postprocess.py`（阈值统一）：
  - 分级评定硬编码阈值（强 75 / 中 65 / 谨慎 60、conf 60/45、模块≥55、模块数≥4/≥3）与 `params_override` 同源化：写入 override 时引擎分档与后处理分级读取同一套生效阈值；不写 override 时默认 75/60 行为与现状完全一致（行为冻结）。
- 全量重放对照（定值证据）：
  - 40 与 50 两个候选各跑一次清缓存后的全量重放，对照综合分分布/买入侧信号数量/分档位移，产物落盘为 `docs/comet/changes/signal-score-correction/` 下的对照报告，作为最终选值依据。
- 回归测试：既有测试中冻结旧语义的断言同步更新（止损卖出不再 ≥60）；`run_all_tests.py` 全量回归保持通过。
- 3% 回撤敏感性子项：引用/复核既有 I12.1 网格证据（`docs/迭代_i12_卖出闭环/卖出规则敏感性网格-*.md`，含 3.0/5.0/8.0/25.0 档、池与 screen 两种口径），在本 change 报告中披露其样本限制与「3% 非偶得」结论的可信度；不重跑网格。

# Non-goals

- 不改突破以外的模块子分（趋势/momentum/量价/形态评分不动）。
- 不做「持仓」信号本身的降分（持仓 60 为中性持有表达，非缺陷）。
- 不调整分档阈值 75/60 之外的策略参数（ATR 止损下限 WIP 等工作区既有未提交改动一律不触碰）。
- 3% 回撤敏感性不重新跑网格（候选池仅 3 只、样本不足），只引用既有证据并披露限制。
- 不改回测管线口径（snapshot/replay/stats/sensitivity 逻辑不变，仅清缓存执行）。

# Acceptance examples

- A1（止损不再反向加分）：在既有止损/卖出计分样例中，突破子分从 60 降至**最终选定值**（40 或 50），满足「≤ 无信号 50 分」且「< 持仓 60 分」；`tests/test_p0_fixes.py` 中冻结「止损卖出 ≥60」旧语义的断言已反转，`test_non_defect_breakout_holding_score_unchanged` 类持仓=60 断言保持通过。
- A2（选值有证据、可复现）：最终选定值（40 或 50）基于**清缓存后**的全量重放对照产出；对照在 40/50 两个候选各跑一次，报告记录综合分分布、买入侧数量与分档位移，且明确注明已清理旧 `cache.json`（避免 policy_hash 只认 postprocess 导致引擎计分改动后旧缓存误用）。代码中以单一可控常量/分支承载最终值，两候选切换成本为零。
- A3（阈值同源、默认冻结）：不写 `params_override.json` 时后处理分级行为与现状逐字节一致（75/65/60、conf 60/45、模块≥55、模块数≥4/≥3 语义不变）；写入 override（如 th_strong/th_buy）后，引擎分档与后处理分级读取同一生效阈值，不再出现「引擎阈值已变、后处理仍用旧常量」的静默不一致（测试覆盖）。
- A4（3% 敏感性对照引用）：change 报告引用既有 `卖出规则敏感性网格-*.md`（含 3.0/5.0/8.0/25.0、池 3 只与 screen 双口径）证据，说明 3% 档结论及其样本限制；不声称新网格证据。
- A5（行为兼容）：非止损/卖出场景的突破子分不变（无信号 50、持仓 60、空头平仓偏多加分的既有样例断言通过）；置信度仅展示维度、不参与评分的不变式保持。
- A6（全量回归）：`python run_all_tests.py` 全文件通过、0 失败；`tests/test_p0_fixes.py` 与 `tests/test_breakout_confidence.py` 全通过。

# Constraints and invariants

- 评分只减不增：除止损/卖出分支外，任何样例的突破子分不因本 change 而提高。
- 模块分只是输入：confidence 与 action 仍由引擎既有规则从综合分推导，不新增评分入口。
- 默认行为冻结：无 override 时引擎阈值与后处理分级全部维持 75/60（65/60/55/4/3 辅助阈值）现状。
- 对照必须干净：所有涉及新分值的效果对照一律清缓存后执行（policy_hash 只反映 `signal_postprocess.py`，不覆盖引擎计分改动）。
- 证据与代码分离：40/50 对照产物是可复现报告，最终选值写入代码常量并同步测试断言，不留「报告说 A、代码用 B」的状态。

# Decisions

- D1 范围 = 三项全做：核心计分修复 + params_override 与后处理阈值统一 + 3% 回撤敏感性对照（用户拍板，2026-09-07）。
- D2 最终分值 = 对照后定夺：40 与 50 都做成候选，清缓存后各跑一次全量重放对照，看综合分/买入侧分布影响后由数据定值（用户拍板，2026-09-07）。
- D3 缺陷范围 = 仅「多头止损/卖出」分支：持仓 60 保留（中性持有表达），空头平仓偏多加分不动，突破以外模块分不动。
- D4 3% 敏感性子项 = 引用既有 I12.1 R2 网格证据（已产出 3/5/8/25 两口径），不重跑，披露样本限制（用户知悉后仍纳入，2026-09-07）。
