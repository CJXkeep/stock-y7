# Capability: 看板内容重构（四问 + 三入口）

## 概述

归档后，趋势看板的默认主路径是：搜一只股票 → 一屏读完四问（趋势 / 买 / 卖 / 风险）→ 需要时展开「为什么」→ 用侧边栏三类入口管理自选、找可买、看档案。

答案全部翻译现有 `/api/analyze`（含后处理）字段，不编趋势切换日，不改策略。本 Spec 取代：

- `beginner-mode` 的默认卡片结构与「小白/专业」作为两套动线的语义（改为「简化/完整」密度档）；风险大白话、术语 chip、「为什么」仍有效，挂到四问卡与 L2；
- `watchlist-sidebar` §1 中「历史/多股一览/信号档案/核心池下拉保持现状」——这些不再是并列一级入口；
- `frontend-improvements-y7` §5 的七个并列侧边栏 tab 与分区头说明句——改为三类入口下的段。

XSS 转义、ECharts 本地化、fetch 超时、术语词典条数、自选分组与服务端 watchlist、扫描弹窗、钉钉设置、FX 档位仍按既有 Spec。

## §1 范围与冻结

- 改动面：`dashboard/index.html`、`dashboard/style.css`、`dashboard/js/*.js`（main/watchlist/journal/scan/ui 等）及 `tests/test_frontend_*.py`。
- **不修改** `analysis/`、`server/signal_pipeline.py` 的后处理规则、`run_analysis` 语义、缠论算法、journal/replay/stats 口径、存储形态。
- 不新增 `/api/tasks`。任务状态仍读既有 `/api/health`、`/api/scan`、`/api/digest`、`/api/notify`。
- 不补 `started_at` / `ended_at` / `invalidation`。没有切换日时趋势行写「当前为{上升|下降|震荡}」，不得虚构日期。

## §2 四问卡（L1，默认唯一权威）

分析成功后，右侧默认可见区域是一张四问卡（可由原 summary + plan + 风险横幅合并，DOM id 可新可旧，但必须同时满足下列可见内容）：

| 问 | 展示 | 字段（后处理之后） |
|---|---|---|
| 趋势 | 方向 + 强度 + 阶段。无切换日则「当前为{方向}」 | `trend.direction` / `trend.strength` / `trend.stage` |
| 买 | 能 / 不能；能买时给出买点与仓位 | 买侧 `action` ∈ {强烈买入, 买入, 谨慎买入}；`trade_plan` 入场/仓位；否则「不能买」+ 后处理否决/观望原因（已有 veto_reason / plain_summary，不新造规则） |
| 卖 | 该 / 不该；该卖时给出卖点 | `sell_signals` 非空或存在止损价则「该卖」+ 止损/卖出点；否则「不该卖」 |
| 风险 | 一条横幅，可展开明细 | `risk_level` + `risk_warnings`；简化模式用既有 RISK_EXPLAIN 大白话 |

- 买/卖判定与同一次分析的后处理结果一致，前端不得另设门槛。
- 买/止损/目标价只出现在四问卡的计划区；summary 旧文案与三段式不得再复述这三价的数字。
- 综合分以后端 `score` 为唯一大数字；不得再把前端 CANSLIM 七维均值画成并列大分。
- 简化模式的三段式（现状/风险与机会/现在该做什么）若保留，只能作为四问卡内部的解说，不得再复制三价数字；完整模式可用一句话总结，结构仍是同一张四问卡。
- 无风险（warnings 与 codes 皆空）不渲染「没有风险」占位。

## §3 证据层（L2 / L3）

- **L2（完整档默认展开，简化档默认收起）**：大盘环境（M 分只在这里以大号展示）、评分总览（五模块 + CANSLIM 七维二级展开）、买卖信号列表（点位跳图、术语 chip、「为什么」保留）、关键价位。
- **L3（两种档都默认收起）**：缠论日/周/分时（可同一卡内页签，互相仍按周期排他显示）、方向一致率。原独立「风险提示」卡删除，明细并入四问卡风险区。
- 用户可手动展开/折叠任一层；模式切换只重置**默认**展开，不阻止手动展开。

## §4 侧边栏三类入口

一级 `sb-tab` 只有：

| Tab | 吸收 | 行为 |
|---|---|---|
| 自选 | 原自选分组窄栏 + 多股行情 | 分组/行情列/信号角标保持 watchlist-sidebar；可在本类下展开「全列表对比」（原 overview 排序列表） |
| 任务 | 扫描档 + 每日速递 | 两段：扫描（分区头「扫描买入」仍打开既有扫描弹窗 + 历史档）；速递（生成/查看既有五大块） |
| 档案 | 浏览记录 + 信号档案 + 核心池 | 三段，各保留原表格/过滤/导出/池编辑能力 |

- 不再有并列的「浏览记录 / 多股行情 / 信号档案 / 核心池 / 速递 / 扫描档」一级 tab。
- 核心池段标题带「手动」；速递内池扫描标题带「自动」。不得再单独使用无前缀的「核心池」同时指两件事。
- 各段仍可有一句 12px 用途说明（frontend-improvements-y7 §5 的说明句迁到段头）。
- `role="tab"` / `tablist` / `tabpanel` / 方向键在**三个**一级 tab 上继续有效。

## §5 顶栏

- 保留：logo、搜索、完整/简化、设置、**自选（仅侧边栏开合）**、行情条、星标加自选。
- 删除：顶栏「历史」按钮。
- 扫描/速递/推送三枚 sys-status pill 不在顶栏常驻；改在「任务」面板状态行展示（数据源仍为既有 health/scan/digest/notify 接口）。
- 「更多」菜单：小屏保留设置/退出等低频项；删除与侧边栏重复的「浏览记录」「扫描买入」。扫描买入只在任务段头。
- 热门股仍在搜索聚焦面板（frontend-improvements-y7 §13 继续有效）。

## §6 密度档

- 按钮文案：「专业」→「完整」，「小白」→「简化」。`body.mode-pro` / `body.mode-simple` 类名可保留以免大面积 CSS 重写，但用户可见标签必须是完整/简化。
- 简化：默认只展开 L1 四问卡；**不**额外露出买卖信号前 2 条。
- 完整：默认展开 L1+L2；L3 收起。
- 切换即时生效，不重新请求；localStorage 模式键沿用 `qs_mode`（值仍可是 simple/pro）。
- ≤420px 仍可切换密度档（frontend-improvements-y7 §9）；图标态标签与桌面一致（完整/简化）。

## §7 轮询（纯前端）

- 当前分析标的若在自选列表中：自选批量刷新命中该 code 时复用最近一次 `/api/quote`（或正在进行的 quote 刷新）结果，不对同一 code 并行再打一遍 quote。
- 不引入新的任务聚合 API；任务面板打开或对应任务 running 时，沿用既有 scan/digest 2s 轮询。

## §8 新手引导

- 三步引导文案改为：①搜一只股票 → ②看右侧四问（趋势/买/卖/风险）→ ③用侧边栏「任务」找可买。标记键可沿用 `qs_onboarded_v1`（已标记用户不强制再看）。

## §9 验收观察点

- 打开已分析股票：未滚动右侧栏即可读完四问；买/卖与该次 `action` 一致。
- `document.querySelectorAll('.sb-tab')` 一级 tab 数量为 3，文案为自选/任务/档案（允许短名）。
- 顶栏无「历史」按钮；有侧边栏开合用的自选按钮。
- 简化模式下买卖信号列表容器默认不可见（折叠或未挂到 L1）。
- `analysis/` 不在本 change 的实现 diff 中。

## 边界与回退

- 分析失败：四问卡不编造成功答案，展示既有人话错误与重试。
- 旧书签/旧 localStorage 分区名：打开已删除的 tab id 时落到「自选」。
- 本 Spec 未覆盖的既有行为保持不变。
