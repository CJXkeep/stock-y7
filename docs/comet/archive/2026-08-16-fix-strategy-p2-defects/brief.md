# Outcome

修复 `docs/策略审核报告.md` 中列出的 P2 级策略缺陷，在保持 P0/P1 修复与总体架构不变的前提下，提升命名准确性、风险控制合理性、形态结果质量与输出透明度。

# Scope

- 将 CANSLIM 重命名，或补充真正的盈利、行业和机构持仓数据（当前实现不是经典 CANSLIM 基本面模型）。
- 将实时量比改为同时间段历史量比，避免盘中早段天然偏低。
- 根据板块/ST 状态参数化涨跌停阈值，不再固定 9.5%。
- 用 ATR/波动率和组合风险预算替代固定 5% 止损。
- 形态结果按确认时间、质量和互斥关系去重。
- 不再吞掉形态检测异常，至少记录可观测错误。
- 在所有输出中显示数据源、复权、最新 bar 状态和计算时间。

# Non-goals

- 不调整 P0/P1 已修复项。
- 不建立历史回测框架，不计算或宣称收益率/回撤/胜率/盈利能力。
- 不提供个股买卖建议或收益承诺。
- 不修改用户界面布局与交互，除非对应输出字段/口径修正需要最小同步。

# Acceptance examples

- A1：CANSLIM 按用户决定重命名或补充基本面数据；输出不再使用误导性的“CANSLIM”名称（若选择重命名）。
- A2：实时量比改用同时间段历史量比；合成数据可验证盘中不同时段不再天然偏低。
- A3：涨跌停阈值根据板块/ST 状态参数化；合成数据可验证不同证券类型使用不同阈值。
- A4：止损由固定 5% 改为 ATR/波动率口径；合成数据可验证高波动/低波动股票止损不同，且输出明确说明。
- A5：形态结果去重后不再出现同一结构重复叠加；合成数据可验证。
- A6：形态检测异常不再静默吞掉；可观测错误被记录/输出。
- A7：API/前端输出包含数据源、复权、最新 bar 状态和计算时间；合成/单元测试可验证。

# Constraints and invariants

- 项目当前无测试框架、无 Git 仓库；测试与验证全部使用纯内存合成数据，不依赖外部行情 API。
- 策略实现修改必须保持与既有“加密版反推”的可解释性；不能为了让测试通过而引入不可解释的黑盒逻辑。
- 前端只做与本次字段/口径修正对应的最小同步改动。
- 所有修复以 `docs/策略审核报告.md` 的 P2 清单为证据边界。

# Decisions

- 使用中文编写产物。
- 测试继续使用 pytest 兼容文件；若环境无 pytest 则退化为纯 Python 等价运行器。
- 修复范围：全部 7 项 P2（用户已确认）。
- CANSLIM 处理：重命名并披露口径（用户已确认）。
- 止损改造：用 ATR 止损替代固定 5%，并在输出中同时显示 ATR 与最大亏损提示（用户已确认）。
