# Outcome

历史信号统计报告能回答两个新问题：**信号是否跑赢大盘**（相对沪深300 的同区间超额收益，各视界超额均值/超额胜率）与**档位是否携带增量信息**（report.md 新增「档位单调性」小节，强烈买入 vs 买入的前瞻收益对比，三态标记）。`python -m backtest stats` 在快照指数数据可用时默认输出超额口径；指数缺失时自动退化为绝对口径并在报告头披露，不报错。依据：`docs/评估模块设计.md` §5.1、§5.2（I8.2）。

# Scope

- `backtest/stats.py`：
  - `compute_forward_returns` 支持可选基准序列（基准收益按**自然日区间对齐**：起点取 ≤ 信号日的最后一个指数收盘，终点取 ≤ 个股该视界结束日的最后一个指数收盘），产出 `r{h}_excess`；
  - `aggregate` 每分组在 `r{h}` 旁增补 `r{h}_excess`（同一 `_summary` 结构，win_rate 即超额胜率）；总体/按动作含超额，按年份/按股票仅绝对口径；
  - `meta` 增基准标记（基准代码/名称，缺失退化标记）。
- `backtest/report.py`：
  - `RESULT_FIELDS` 追加 `r5_excess..r60_excess` 列；
  - 口径声明增三行：基准与超额口径（含自然日区间对齐说明）、档位单调性标记说明、幸存者口径（回放范围为当前自选池）；
  - 新增「超额表现（相对沪深300）」小节（总体 + 按动作）与「档位单调性」小节（置于按动作拆分之后）。
- `backtest/cli.py`：stats 命令透传（无新 flag，超额默认开启）。
- 测试：新增/扩展 `tests/test_stats.py` 覆盖 A1–A3（合成数据离线）。

# Non-goals

- 阈值敏感性扫描与 `action_from_score` 抽取（I8.3 单独 change）；
- 信号日志口径（最终 action，含谨慎买入档）的统计与档位检验；
- 组合级模拟与年化/MDD/夏普家族；
- 每日速递（digest）任何改动；
- 等权核心池基准、全收益指数口径；
- 存量 `results.csv` / `report.md` 回刷；
- by_year/by_symbol 的超额列（避免报告膨胀）。

# Acceptance examples

- **A1 超额手算**：合成快照（个股 + 000300 指数日线）上运行 stats，任取一信号的 `r20_excess` 与手工按日历区间取指数收盘计算的结果精确一致；构造个股停牌顺延案例，验证基准区间随个股视界结束日同步拉长。
- **A2 无基准退化**：从快照剔除指数 bars 后重跑 stats，报告头出现"无基准/仅绝对口径"披露，绝对口径各表正常产出，进程不报错，`meta` 标记退化。
- **A3 单调性渲染**：构造两档样本均 ≥10 与任一档 <10 两种数据，三态标记（单调/不单调/⚠样本不足）正确；缺档（如重放口径无谨慎买入）显式注明不参与原因。
- **A4 回归**：`python run_all_tests.py` 全绿；既有 report.md 渲染在无新数据时行为不回归（新小节缺失基准时优雅跳过或注明）。

# Constraints and invariants

- 口径单一来源（`docs/评估模块设计.md` §3）全部不变：forward return 按个股自身 bar 计数、去重/warmup/SAMPLE_MIN/双 action 口径不可混用。
- 无前视硬约束不变：超额仅用于事后统计，不进入信号生成；快照校验行为不变。
- 纯标准库，无新依赖。
- 结论只取去重后口径；新表沿用 n<SAMPLE_MIN「⚠样本不足」规则。
- 统计为信号与市场环境的复合结果，非因果；自用参考，非投资建议（报告既有声明保留）。

# Decisions

- **D1 基准 = 沪深300（000300）**：宽基多头基准，快照已含其日线；等权核心池基准引入组合收益新口径，留 v6（设计文档 §10.1）。
- **D2 超额默认开启、无 CLI 开关**：指数缺失自动退化并披露——少一个 flag 就少一种口径漂移。
- **D3 基准对齐用自然日区间**：不按指数自身 bar 计数，个股停牌顺延时指数必须跨同样日历区间，否则超额归因错位。
- **D4 单调性只披露不判显著**：输出相邻档差值与两档 stderr，三态标记（单调/不单调/⚠样本不足）；不做显著性宣称，防止把判读自动化成新自由度（诚实原则）。
- **D5 单调性判据用超额均值**（有基准时），无基准退化为绝对均值；标记口径在小节标题注明。
- **D6 观望/谨慎买入缺档显式注明**：观望无 forward return 样本；谨慎买入仅存在于最终 action 口径，重放口径无此档。
- **D7 用户确认（2026-08-29）**：按设计实施 I8.2（D1–D6 全部确认）；I8.2 验收归档后自动接续创建 I8.3（阈值敏感性扫描）change。
