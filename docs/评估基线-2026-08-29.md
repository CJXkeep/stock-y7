# 评估模块首次实盘基线（2026-08-29）

> I8.2（超额收益+档位单调性）/ I8.3（阈值敏感性）交付后的首次真实数据运行记录。
> 快照 750 根日线（约 3 年），forward return 口径见 `docs/评估模块设计.md` §3；统计为信号与市场环境的复合结果，非因果；自用参考，**非投资建议**。
> 复跑方式：`python -m backtest snapshot && python -m backtest replay <id> --workers 8 && python -m backtest stats <id> && python -m backtest sensitivity <id> --thresholds "70,65" --thresholds "85,75"`。

## 基线一：评估池（20 只流动性大盘股，行业分散）

快照 `20260829T084359Z`（临时目录运行，含自选 601800/000630）；落盘 4487 笔 → 去重 → 排除预热 → **487 笔参与统计**。

| 口径 | 总体 r20 | 总体 r60 | 强烈买入(75 笔) r20 | 买入(412 笔) r20 |
|---|---|---|---|---|
| 绝对（胜率/均值%） | 48.38 / +0.93 | 54.57 / +3.02 | 60.27 / +2.45 | 46.15 / +0.64 |
| **超额（相对沪深300）** | 43.63 / **−0.22** | 40.87 / **−1.51** | 47.95 / +1.15 | 42.82 / **−0.48** |

**结论**：
1. **超额口径反转了绝对口径的读法**——这批大盘股信号的绝对上涨大部分是大盘 β，池子整体层面 r20/r60 超额为负；只看绝对胜率会偏乐观。
2. **档位单调性在锚点 75/60 下四个视界全部成立**（超额差值 +0.62/+0.94/+1.63/+2.62pp），"强烈买入"档携带真实增量信息；但 stderr 宽（r60 处 ±1.98），方向一致 ≠ 显著。
3. **阈值敏感性边界清晰**：(70,65) 打破 r5/r10 单调；(80,70) 强烈买入仅 5 笔全样本不足；(85,75) 无档间可比。**75/60 是稳健锚点，无证据支持上调**。

## 基线二：个人核心池（601800 中国交建 + 000630 铜陵有色，pool.version=1）

快照 `20260829T085441Z`；落盘 376 笔 → 去重 → 排除预热 → **41 笔参与统计**。

| 口径 | 总体 r20 | 总体 r60 |
|---|---|---|
| 绝对（胜率/均值%） | 55.26 / +3.66 | 52.78 / +10.82 |
| 超额（相对沪深300） | 50.00 / +2.15 | 58.33 / **+6.10** |

- 个人池信号在 r60 跑赢基准 +6.10%（58.3% 胜率）——与评估池的负超额形成对照，α 高度依赖具体标的。
- **强烈买入仅 6 笔，全部标 ⚠样本不足**，档位结论待样本积累。
- 按年份拆分（诚实提醒）：2025 年 n=27、r20 均值 +7.57%；**2026 年至今 n=14、r20 −5.91%**——近期信号表现显著转差，评估是"信号×环境"的复合结果，环境切换时历史胜率不可外推。

## 使用约定

- 核心池变更后需重建快照（pool.version 校验会拒绝旧快照，`--allow-stale` 仅放行对照）；
- 每次重跑 stats/sensitivity 生成新结果目录，`data/results/` 不回刷历史；
- 信号日志（真实前向样本）持续累积后，与重放统计互相印证。
