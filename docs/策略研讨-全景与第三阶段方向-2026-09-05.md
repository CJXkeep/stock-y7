## 一、当前策略全景（代码事实）

### 1.1 买入决策全链路

```
K线/行情/资金流/指数/宽度
  ↓ run_analysis（signal_engine.py）
五模块打分：趋势25% / 动量20%(CANSLIM) / 突破20% / 量价20% / 形态15%
  → score 三档：≥75 强烈买入 / ≥60 买入 / 否则观望（params_override 可覆盖两阈值）
  → trade_plan：止损=entry−2×ATR(14)（过窄/过宽兜底 95%）；目标=形态量度→箱体上沿(须>entry)→+10%估算
  ↓ apply_signal_policy（signal_postprocess.py，I10 起全项目单源，policy.v1.gate）
①硬否决：跌破MA20 / 价跌量增 → 观望
②策略门：趋势下降 / 市场宽度 M<30 → 观望（第一性原则 2026-08-31 落地）
③分级重评：强烈买入须 conf≥60 且 ≥4 模块≥55；买入须 conf≥45 且 ≥3 模块≥55
④软否决：MA20下行 / 受压MA60 / OBV走弱 → 降一级
⑤目标来源降级：强烈买入但目标=+10%估算 → 降为买入
⑥M 分仓位：<40 轻仓+降档 / <55 半仓
⑦盈亏比 <1.0 → 观望
  ↓ 消费端
看板/扫描/推送（最终口径）｜无前视重放（raw+final 双落盘）｜模拟账户 QushiV5Adapter→Decision
```

## 三、本次研究新发现的结构性弱点（代码证据）

### 3.1 信号侧永不产出卖出 action（最重要）

- `action_from_score` 只有 强烈买入/买入/观望 三档（signal_engine.py:63-77）；后处理只降不升；
- `_ACTION_TO_DECISION` 的 "卖出"/"强烈卖出" 键是死键（sim_strategy.py:63-64）；sell_queue 恒空（sim_service.py:226-232）；REASON_SIGNAL 死路径（sim_service.py:450-458）；
- 引擎 sell_signals（突破多头止损、OBV/主力流出、momentum ⚠️）只是文案，不参与任何评分与 action。

**后果**：持仓退出 100% 依赖 static stop/target + exit_check 四规则；「该卖」这件事没有任何与买入同源的证据链。

### 3.2 卖出规则零回测路径（与诚实条款的张力）

- replay 只落 `BUY_ACTIONS=("强烈买入","买入")`（replay.py:30,68，不含谨慎买入）；
- exit_check 四规则、static stop/target 均无重放评估路径——`docs/第一性原则 §5` 的「若过滤后没有稳定增量，撤回」对卖出规则**无法执行**，因为卖出规则从未被评估过；
- 四规则中的 3% 高点回撤是外部 078 的拍定参数，未经本项目实证（外部对照样本 082 用 25% 宽回撤，两极之间未做敏感性）。

### 3.3 突破模块对止损信号不敏感甚至反向加分

`_breakout_to_score`：「多头止损/卖出」= 60 分 = 「持仓」，比「无信号」50 分高 10 分（signal_engine.py:126-142）。刚触发海龟止损的股票，突破子分反而高于从未突破的股票。

### 3.4 重复计分精确清单（第一性原则「同一事实只贡献一次」的欠账）

| 同一事实 | 消费点 |
|---|---|
| 20 日涨幅 | 趋势 resonance（trend_module.py:140）与动量 C（momentum_module.py:80）完全同式双计 |
| 价格 vs MA20 | 趋势 45 分 + 引擎 risk_code + 后处理硬否决 + 突破置信度 ±10/12 + exit_check + 动量 M（指数侧）共六处 |
| 成交量 | 动量 S（5日均量基准）、量价（3日均量+量比）、突破置信度（20日均量）三口径 |
| 资金流 | 量价修正 ±15/±10 与动量 I 分双计 |
| 新高 | 动量 N 120日新高与唐奇安 20/55 突破同构，杯柄突破再判一次 |

第一性原则的决策（保留分数、不靠加指标解决）依然成立，但候选缓解路径见 §5（乖离率动量）。

### 3.5 其他（按影响排序）

- **两套 confidence 同名不同义**：引擎 conf=score×0.8+12n−40（进后处理分档）vs 海龟 evaluate_confidence（仅展示过滤），Decision.confidence 载前者——语义混淆点；
- **模拟账户两阶段评估口径分裂**：初筛无资金流（I=50 默认），命中买入档才补拉重跑——同一次 screen 内同一标的被跑两遍，记录的「信号」非初筛的「信号」；
- **params_override 与后处理脱节**：override 只覆盖引擎 75/60，后处理分级阈值 75/65/60、conf 60/45、模块≥55 全硬编码——调 override 会造成引擎档位与策略门档位静默不一致；
- **止损三套口径并存**：引擎 entry−2×ATR(14)（模拟账户 static stop 用它）、海龟 last_add−2N（仅展示）、stats 兜底次日开盘×0.95（评估口径）——防守位无单一事实源；
- **下降趋势双门近冗余**：trend_down 策略门触发条件是硬否决 price_below_ma20 的子集，增量仅存于文本回退兜底；
- **后处理文本回退否决脆弱**：无 risk_codes 时按中文关键词匹配信号文本决定否决——上游文案改动会改变否决行为；
- **A股无做空但空侧逻辑消耗链路**：空头入场/空头平仓参与评分（空头平仓还 +3 偏多）。

### 3.6 参数集中度

撮合/调度/门槛类参数单源 `backtest/config.py`（预承诺纪律良好）；但**信号语义参数**（五模块全部加减分值、窗口、权重、后处理分档边界）几乎全部硬编码散落各 analysis 模块——这是 §3.4/3.5 一致性风险的根因。

## 五、第三阶段方向建议（按价值排序，供拍板）

### 第 1 优先：信号驱动卖出 + 卖出侧证据闭环（B1+B2，出处 094/078/011/106）

同时解决 §3.1（卖出缺位）与 §3.2（卖出无评估）——这是唯一「不做就无法回答」的空白：第一性原则的撤回条款对卖出规则目前无法执行。

建议形态：
1. **先通评估路径**：重放增加持仓侧视角（对已入场信号持续打分，落盘 final 卖出触发点与 forward return），让「分数跌破阈值卖出」有 SCREEN_GATE 可评的样本；
2. **再做账户层**：`sim_strategy` 增加持仓每日复评（复用 run_analysis+policy，分数<阈值→卖出 Decision），**默认关**，与 static stop/exit_check 的优先级明确（四规则优先，信号分兜底）；
3. 时间止损（N 日未达 +1R 减持）作为第二变量，同样默认关；
4. 滚动评估对照开/关两组。

> 2026-09-05 已按本项排定 **I12 设计稿**：`docs/迭代_i12_卖出闭环/卖出侧证据闭环设计.md`（待拍板 Q1–Q4）；路线图 §十一 同步。

### 第 2 优先：低成本计分修正（确定性高、无须等样本）

- **突破模块止损信号计分修复**（§3.3）：止损/卖出从 60 分改为低于中性（如 40），或至少不高于 50——刚止损的股票不该比从未突破的股票分高；影响综合分口径，须走 params_override 同款预承诺+全量重放对照；
- **3% 回撤止盈敏感性对照**：用现成 sensitivity 工具对 3%/5%/8%/25%（082 口径）做扫描，确认 3% 不是偶得值；
- **params_override 与后处理阈值统一**：后处理分级阈值进 config 或 override 同源，消除静默不一致。

### 第 3 优先：波动率目标仓位缩放（B3，出处 118/045）

纯标准库 ≤20 行；把金字塔加仓从「单位数固定」升级为「单位风险固定」；只缩每单位金额、不动 2N 止损口径；sensitivity 扫 0.5/1.0/2.0 边界。

### 第 4 优先（披露先行）：环境门双确认（B4+B9）

牛熊迟滞状态机先做**披露字段**（BULL/BEAR/NEUTRAL 进信号单），行业宽度并入现有行业动量池做 B 级过滤；滚动评估证明增量后再考虑升格为门——吸取 RSRS 门「默认关=零证据」的教训。

### 暂不做

基本面因子门槛（样本与数据源约束）、机器学习/日内/均值回归全类（§4.4）、重复计分的立即重构（第一性原则已拍板保留分数连续观察；B7 乖离率动量作为单独立项候选，不与卖出侧混在同一个 change）。

## 六、000931 案例：证据系统的正面样板

一根 K 线（08-27 盘中 5.96 破 5.74 通道、收盘 5.70 回落）暴露三个问题并全部闭环：

1. **假突破不构成买点**：收盘确认口径（`_find_last_entry`），与 evaluate_confidence 的假突破判定同源；
2. **出局校验须用实际仓位止损**：加仓后止损 last_add−2N=4.93 已于 09-01 收盘触及，旧口径用简单 entry−2N=4.44 永不触及，把已出局仓位标成高置信买点；
3. **已出局买点不再画成有效买点**：chart.js isWeak 口径修复（离场不受置信度门槛绕过），46%/52% 已出局买点弱化为灰色「参考」，不再画入场/止损线与头肩底目标线叠出矛盾信息。

配套：假突破惩罚 −15→−30 + 收盘未守稳封顶 59；87 根冻结样本回归 3/3；规格 `docs/comet/specs/breakout-buy-point/spec.md` v2。

**方法论价值**：失败证据被保留并弱化展示（而非掩盖），问题在单一个股复盘后立刻上升为口径级修复+冻结回归——这正是「绝不自欺」纪律的执行样例，也是 §5 第 2 优先项（计分修正）应遵循的流程模板。
