## 二、signal_engine 五模块评分体系

### 2.1 总分构成(从 description 字段反推)

```
综合分 = 趋势×25% + CAN_SLIM×20% + 突破×20% + 量价×20% + 形态×15%
```

实测样例(贵州茅台 600519)：
```

score = 68
description = "综合68分 | 趋势=上升(75) | 量价=量价齐升(82) | 突破=60 | CS=B(55) | 形态=72"
```

### 2.2 各模块评分子项(常量池 + 输出结构还原)

#### 趋势模块 trend_module

| 子项 | 权重线索 | 依据 |
|---|---|---|
| ma20_dir | 30分 | ma_scores={ma20_dir:30, ma60_dir:0, price_vs_ma20:15, price_vs_ma60:10, resonance:20} |
| ma60_dir | — | 同上 |
| price_vs_ma20 | 15分 | 同上 |
| price_vs_ma60 | 10分 | 同上 |
| resonance(均线共振) | 20分 | 同上 |

**辅助函数**(常量池确认)：
- `_sma.py` — 简单移动平均
- `_ema.py` — 指数移动平均
- `_ma_direction.py` — 均线方向：`未知/向上/向下/走平`(用 MA 斜率判方向)

输出结构：
```json

  "ma_arrangement": "多头排列", "ma_scores": {...},
  "trendline": null, "signals": ["MA20向上", "站上60日决策线"]
}
```

- **评分**：`_volume_price_to_score` 按 看涨/看跌 模式打分
- **模式判断**(黑盒观察)：`量价齐升 / 缩量回调 / 放量滞涨 / 价跌量增` 等

#### 突破模块 breakout_module(海龟交易法则)

常量池确认的三个核心函数：
- `calc_true_range.py` — `TR = max(H-L, |H-PDC|, |L-PDC|)`
- `calc_n.py` — `N值 = 前N日TR的简单移动平均`(ATR)
- `_find_last_entry.py` — 查找最近一次突破入场记录，返回 `(方向, 入场价, 入场日索引)`

**系统一(20日唐奇安通道)** / **系统二(55日唐奇安通道)**：
- 突破通道上沿 → 入场；跌破2N止损
- 加仓规则：价格每上涨 0.5N 加仓一次(实测量化：`next_add_price`)

#### CANSLIM 模块 canslim_module

常量池确认的评分函数：

| 维度 | 算法(常量池还原) |
|---|---|
| C(近期动力) | 近期价格涨势 |
| A(中期趋势) | 中期价格趋势 |
| N(新高形态) | 是否创新高/新底部 |
| S(供需关系) | 换手率/量价配合 |
| L(领涨强度) | 相对大盘强度 |
| **I(机构资金)** | `_calc_i_score`：无机构持仓数据→用资金流替代。5日主力净流入/净流出、超大单5日净流入、主力连续N日净流入、主力净占比 |
| **M(大盘环境)** | `_calc_m_score`：有指数→大盘MA20>MA60(多头)/MA20向上/上证20日涨跌幅；无指数→fallback个股均线(精度降低) |
| 评级 | `_calc_grade`：A+/A/B+/B/C+/C/D |

## 四、后处理优化体系(app.py 明文)

这是加密模块之外、完全明文的"股神级风控"，共 7 步：

### 4.1 硬否决(HARD_VETO)
```
跌破MA20 → 价格跌破MA20，趋势已坏
价跌量增 → 价跌量增，恐慌抛售信号
OBV下降/走低/下行 → 量能走弱
```
命中即 `action = "观望"`。

### 4.2 软否决(SOFT_VETO)
```
MA20向下/下行 → 短期趋势偏弱
受压60日 → 上方压力大
```
命中降一级(强烈买入→买入→谨慎买入)。

### 4.3 分级体系
```
score≥75 且 conf≥60 且 ≥4模块>55分  → 强烈买入
score≥65 且 conf≥45 且 ≥3模块>55分  → 买入
score≥60                              → 谨慎买入
否则                                  → 观望
```

### 4.4 M分驱动仓位管理
```
M<40  → 轻仓(1/4)，且降级
M<55  → 半仓(1/2)
M<65  → 原仓位或半仓
M≥65  → 原仓位或正常仓位
```

### 4.5 盈亏比检查
```
RR<1.0 → 否决(倒挂不入场)
RR<1.5 → 谨慎操作
RR<2.0 → 勉强达标
RR≥2.0 → 风险收益比良好
```

### 4.6 M分修正(市场宽度)
```
breadth_ratio≥0.7 → +15(广度强)  ≥0.6 → +10   ≥0.5 → +5
≥0.4 → -5   ≥0.3 → -10   <0.3 → -15
```

### 4.7 写回
`optimized_action` / `original_action` / `veto_reason` / `position_advice` / `risk_notes` / `risk_reward`，并重写 `plain_summary` 前缀。

## 五、缠论模块实现分析

### 5.1 缠论日线(chanlun_daily)

流水线(常量池 + API 输出还原)：
```
K线(250根) → 包含处理(合并相邻K线) → 分型识别(顶/底分型)
           → 笔划分(相邻分型连接) → 中枢识别(ZG/ZD/ZZ)
           → 背驰判断(MACD面积比较) → 买卖点标记(buy1/2/3, sell1/2/3)
```

关键确认点：
- `find_daily_fractals.py` — 分型识别(top/bottom)，188根合并K线产出84个分型
- **笔**带 `macd_area`(该笔MACD面积)与 `has_divergence`(是否背驰)字段
- **背驰判据**(信号描述反推)：
  - 一买 = 下跌笔背驰(MACD面积衰减，如 `当前段29.8 vs 前段衰减`)：`"一买点：走势底背驰，MACD面积29.8较前段衰减，空头动能减弱"`
  - 二买 = 一买后反弹再回调不破前低：`"二买点：一买点后反弹再回落，未破前低1368.03"`
  - 三卖 = 中枢向下突破后反抽不回中枢：`"三卖点：中枢[1404.98-1430.86]向下突破后反抽，未回到中枢内"`
- **置信度**与背驰衰减幅度正相关(86/70/75 等)

输出结构：
```json
{
  "kline_count": 250, "merged_count": 188, "fractal_count": 84,
  "stroke_count": 20, "zhongshu_count": 9,
  "current_state": "...", "summary": "...", "description": "...",
  "signals": [{"type": "buy1", "type_name": "一买点", "price": 1368.03,
               "date": "2025-11-05", "description": "...", "confidence": 86}],
  "fractals": [{"type": "top", "type_name": "顶分型", "price": 1447.02, "date": "2025-07-24"}],
  "strokes": [{"direction": "down", "start_price": 1447.02, "end_price": 1362.02,
               "start_date": "2025-07-24", "end_date": "2025-08-04",
               "macd_area": 0.0, "has_divergence": false}],
  "zhongshus": [{"start_date": "2025-07-24", "end_date": "2025-10-13",
                 "zg": 1413.09, "zd": 1362.02, "zz": 1387.55,
                 "is_broken": true, "break_direction": "up"}],
  "chart_signals": [...ECharts标注...], "chart_fractals": [...],
```

### 5.2 缠论分时(chanlun_minute)

常量池确认的流水线：
```
1分钟分时(240点) → construct_5min_klines(5分钟K线, 午休分割)
   上午 09:30-11:30(120分钟) / 下午 13:00-15:00(120分钟)
   → _make_kline(转5分钟K) → 分型/笔 → _calc_divergence_confidence(MACD面积衰减→背驰置信度)
   → 买卖点(sell1/buy1 等)
```

`_calc_divergence_confidence`：`"MACD面积衰减越多，置信度越高"`——分时一卖置信度90的样例即源于此。

## 八、辅助验证手段

1. **采样反推阈值**：对同一股票修改 K 线数量/时间窗口，观察 score 变化反推各子项权重。
2. **交叉验证**：用明文指标库(如 talib)复算 MA/ATR/OBV/MACD，比对输出字段值。
3. **缠论正确性验证**：人工在 K 线图上核对分型/笔/中枢端点是否与 API 返回一致。
4. **M分修正验证**：breadth 修正前后 m_score 差值 = ±15 阶梯(明文已知)。
5. **边际扰动**：构造单因子变化(如仅 MA20 方向)，观察 action 是否被软/硬否决(明文规则可精确预测)。
