## 1. R1 小白模式增强 —— "让不懂的人看懂并知道该做什么"

### 1.1 风险提示置顶（修 Bug + 增强）
- 小白模式下**风险卡片永不折叠**（从 setMode('simple') 的折叠清单移除 risk）；
- 有风险时在「AI 分析结论」卡**顶部**渲染红/橙渐变横幅，置顶于结论正文之前；
- 专业模式保持现状（右侧独立风险卡）。

### 1.2 风险逐条大白话解读
前端内置 `RISK_EXPLAIN` 字典（key 复用后端 `risk_codes` 结构化码）：

```
price_below_ma20   → "股价跌破20日均线（短期趋势生命线），趋势转弱"
                     建议："不宜急于买入，等待站回均线再考虑"
obv_down           → "OBV能量潮下降：买入的资金在变少，上涨缺乏支撑"
m_score_low        → "大盘环境偏空：多数股票在跌，此时买入容易'逆水行舟'"
risk_reward_low    → "预期收益小于潜在亏损，这笔买卖不划算"
```
每条 = 大白话解释 + "对你意味着什么" + "建议动作"，小白模式默认展开第一条。

### 1.3 结论三段式改版（小白模式）
把一句 plain_summary 扩成三段（全部由现有 signal 字段在前端拼装，零后端依赖）：
- 📌 **现状**：处于下降趋势，主力资金流出（复用 trend/vp/momentum 字段）
- ⚠️ **风险/机会**：风险等级高——多数信号偏空（复用 risk_level/buy_signals/sell_signals）
- ✅ **现在该做什么**：观望，等收盘价站回 MA20（1279 元）再关注；若买入建议仓位不超过 1/4
专业模式保留原一句话总结。

### 1.4 术语即点即译
- 内置术语词典（MA5/20/60、OBV、ATR、盈亏比、换手率、缠论一/二类买卖点、中枢、M分、CANSLIM…）；
- 正文与信号列表中的术语渲染为虚线下划线 chip，点击弹出气泡卡（复用 v4.0 关键价位悬浮注释机制）；
- 词典放前端常量，后续可挪后端统一维护。

### 1.5 信号逐条"为什么"
买卖信号列表每条可展开：规则原文 → 大白话解释 → （P3）结合 journal 历史胜率显示"该信号历史20日胜率 xx%"。

**验收**：小白模式下风险横幅必现且不可折叠；任意结论中的术语均可点开解释；三段式完整展示；专业模式视觉不变。

## 2. R2 自选股侧边栏 + 分组 —— 对标同花顺

### 2.1 布局改造
- 新增**常驻左侧边栏**（宽 260px），可一键收起为 48px 图标栏（状态记忆 localStorage）；
- 顶栏「自选」按钮改为开合侧边栏；历史/多股一览/信号档案/核心池保留在下拉面板（控制本次范围）；
- 主区（图表+右栏）自适应剩余宽度，ECharts resize 监听。

### 2.2 数据模型与迁移（纯前端，向后兼容）
```js
// localStorage: qs_watch_groups（新）
[{ id, name, order, collapsed, codes: ['600519', ...] }]
// 迁移：首次加载检测旧 qs_watchlist 平铺数组 → 自动转入"我的自选"分组，旧键保留不删（回滚安全）
// 股票详情仍复用旧结构 {code,name,action,score,...} 存 qs_watch_stocks，groups 只存 code 引用
```

### 2.3 分组交互
- 新建/重命名/删除分组（删除时成员回落"我的自选"）；拖拽排序分组与股票；
- 股票行：名称/代码/现价/**涨跌幅**（红绿）/信号角标（买/卖/观）；
- 行为对齐同花顺：单击切换分析标的（侧边栏不收起）、星标快捷加当前股到选中组、右键菜单（移动到分组/置顶/删除）；
- 组头显示：成员数 + 组内涨跌统计（3涨2跌）。

### 2.4 行情刷新策略
- P1 先复用现有并行 fetch（多股一览已有同款逻辑），交易时段 5s 一轮，非时段 60s；
- P3 后端加批量接口 `GET /api/quotes?codes=a,b,c`（一次请求返回全部，替代 N 个并发请求，降低东财被 WAF 拦概率）。

### 2.5 导出兜底
localStorage 换浏览器即丢 → 设置面板加「自选导出/导入 JSON」，成本一天以内，解决数据安全感问题（真正的云端同步不在本迭代）。

**验收**：老用户升级后自选自动进默认分组无丢失；分组增删改拖拽全可用；盘中侧边栏行情 5s 刷新且涨跌变色；收起/展开状态记忆。

## 3. R3 动效系统 —— 三档开关，默认自动

### 3.1 全局 FX 开关
设置弹层（顶栏新增 ⚙）→ 动效档位：
- **关**：一切动画禁用（body.fx-off 一刀切），适合低配机/省电；
- **标准**（默认推荐）：微交互 + 内容入场，图表仍静态渲染；
- **炫酷**：标准之上叠加图表动画与氛围效果；
- **自动**：默认值。`deviceMemory<4 或 hardwareConcurrency<=4 或 prefers-reduced-motion → 关`，否则标准。
localStorage `qs_fx` 记忆；`prefers-reduced-motion: reduce` 时强制关（无障碍合规）。

### 3.2 动效清单（按档位）

| 效果 | 标准 | 炫酷 |
|---|---|---|
| 卡片进入 stagger 淡入上滑 | ✅ | ✅ |
| 分析分数数字滚动（rAF count-up） | ✅ | ✅ |
| 自选星标 pop、按钮 hover 微交互 | ✅ | ✅ |
| 骨架屏替换转圈 loading | ✅ | ✅ |
| 页签/视图切换 crossfade | ✅ | ✅ |
| ECharts 入场动画（仅首次 setOption，刷新仍 false） | ❌ | ✅ |
| 信号变更角标扩散 ring + 价格闪烁 | ❌ | ✅ |
| 结论徽章呼吸光晕、侧边栏滑入弹性 | ❌ | ✅ |

### 3.3 性能护栏（写死在代码规范里）
1. 只动 `transform/opacity`（合成层），禁止 width/top/left 动画；
2. ECharts 动画只在炫酷档、只作用于首帧渲染，轮询刷新永远 `animation:false`（保住现有性能决策）；
3. 数字滚动用 requestAnimationFrame，页签隐藏时暂停；
4. FX=关 时 JS 侧跳过动画调度逻辑（不是靠 CSS 硬扛）；
5. 侧边栏列表渲染用 DocumentFragment，避免逐节点 reflow。

**验收**：三档切换即时生效并记忆；关档下 CPU/GPU 占用不高于当前版本；炫酷档在 i5 集显笔记本上 K 线缩放不掉帧；reduced-motion 用户强制无动画。
