# 信号时点语义说明

> 适用范围：缠论日线/周线（`analysis/chanlun_daily.py`）与缠论分钟线（`analysis/chanlun_minute.py`）输出中的买卖点信号。
>
> 目的：避免把“后续 K 线确认后才可知”的信号回填到历史分型日期，防止在回测或复盘时产生前视偏差。

## 三个时点

每个信号都携带三个时点字段：

| 字段 | 含义 | 日线/周线 | 分钟线 |
|---|---|---|---|
| `observation_date` / `observation_time` | 信号所依赖的价格极值实际出现的 K 线日期/时间（即笔端点），仅代表“观察到该端点”，不代表当时已可确认信号。 | 笔的 `end_date` | 笔的 `end_time` |
| `confirmed_date` / `confirmed_time` | 该笔被后续分型确认、信号真正可知的日期/时间。若为 `None`，表示当前数据末端尚无后续分型确认，信号尚未成立。 | 后续同类型分型的日期 | 后续同类型分型的时间 |
| `executable_date` / `executable_time` | 默认的下一可成交时点：确认时点之后的下一个 K 线日期/时间。若不存在（确认时点已是数据末端），则为 `None`，表示当前还不能执行。 | `confirmed_date` 的下一个日期 | `confirmed_time` 的下一个 5 分钟 K 线时间 |

## 使用约定

- 回测/复盘时，应使用 `confirmed_date` / `confirmed_time` 作为“信号可知时间”，使用 `executable_date` / `executable_time` 作为“可成交时间”，不要使用 `date` / `time` 作为成交时点。
- `date` / `time` 字段仍保留为图表定位用的历史端点坐标，仅用于展示，不用于判定信号何时可知。
- 当 `confirmed_date` / `confirmed_time` 为 `None` 时，该信号应视为“尚未确认”，不应作为已成立信号用于回测或执行。
