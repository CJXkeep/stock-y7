# I11 迭代设计：持仓级净值归因（模拟账户贡献拆解）

> 状态：已实现（2026-09-04）；对应版本路线图「剩余展望 #3：持仓级净值归因（哪只股票 / 哪个档位贡献或拖累超额）」。

## 一、动机

模拟账户已有组合级指标（年化/回撤/夏普/卡玛 + 超额），但「哪只股票 / 哪个档位贡献或拖累了收益」无处可看——证据系统纪律要求归因可解释：账户层面赚了/亏了，要能下钻到标的与档位。

## 二、范围内 / 范围外

**范围内**（全部为披露，不设门槛，遵守 I9「分档只披露」纪律）：

- 按标的（symbol）/ 按档位（level）拆解**已实现**贡献：来源于 `trades.jsonl` 平仓笔（`side=sell`）的 `pnl/pnl_pct/hold_days/fees`；
- 按标的 / 按档位拆解**浮动**贡献：来源于当前持仓估值视图（`position_view`）；
- 合计 = 已实现 + 浮动，降序排列，看板新增「贡献拆解」分区卡；
- 账户重置（`reason=reset`）审计笔**不计入**贡献，单独计数披露。

**范围外**：

- 不做时间加权（TWR）逐期归因——`equity.jsonl` 无 per-symbol 市值快照，列为后续增强；
- 不做超额（相对基准）归因——单笔交易无基准对齐口径，超额归因只能走 replay→stats 管线（`stats.py by_symbol` 已有绝对口径披露）；
- 不做门槛/结论：n<10 的组不标注统计结论，胜率/均值仅披露。

## 三、实现

### 3.1 内核（`backtest/sim_account.py`）

新增纯函数 `contribution_summary(trades, positions=None)`（置于 `compute_metrics` 后）：

- 输入：全量成交流水（`load_trades()` 无 limit）、持仓估值视图列表（`portfolio_summary().positions`）；
- 已实现：逐笔 sell（剔除 `reason=reset`，单列 `reset_count/reset_pnl`）按 symbol / level 聚合
  `realized_pnl / closed_count / win_rate / avg_pnl_pct / avg_hold_days / fees`；
- 浮动：逐仓按 symbol / level 聚合 `unrealized_pnl / market_value / position_count`；
- 输出：`{"by_symbol": [...], "by_level": [...], "total": {...}, "note": ""}`，行内
  `total_pnl = realized_pnl + unrealized_pnl`，按 total_pnl 降序；
- 离线纯函数，不读盘不联网，可独立测试。

### 3.2 服务层（`server/sim_service.py`）

`handle_sim_get` 改为全量读取流水（`load_trades()`），展示切片沿用 `SIM_TRADE_LOG_LIMIT` 语义，
`contribution_summary` 聚合结果挂载到载荷新增 `contribution` 键。

### 3.3 看板（`dashboard/sim.html` + `dashboard/js/sim.js`）

- `sim.html` 新增「贡献拆解」卡片（容器 `#sim-contribution`），位于持仓/流水区之后；
- `sim.js` 新增 `_renderContribution`：按标的、按档位两张表（已实现 / 浮动 / 合计 / 平仓笔数 /
  胜率 / 均收益率 / 均持有天数 / 持仓市值），档位沿用 LEVEL 中文映射；
- 无数据时显示占位说明。

## 四、口径与披露纪律

- 胜率/均值为简单平均，样本少仅参考；`avg_hold_days` 沿用自然日口径（与 trades 写入口径一致）；
- `manual` 档位（手动买卖）参与聚合但按 strategy 单列展示时保留原值；
- 披露非投资建议；本模块不改变任何写入路径，纯读取聚合。

## 五、验收

- `tests/test_sim_contribution.py`：聚合正确性 / reset 剔除 / 浮动合并 / 空数据 / 源码接线断言；
- `python run_all_tests.py` 全绿。
